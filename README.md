# Mamikos Clone – Frontend Technical Test

## Overview
A simple clone of the Mamikos homepage built using an AI-assisted development approach. The focus was on recreating the core visual elements of the Mamikos website: navbar, search bar, carousel, and footer.

## Tech Stack
- **React**
- **Tailwind CSS**

## Approach
The project was built iteratively with the help of an AI coding assistant — starting from scaffolding the page structure, building out each section (navbar, hero + search bar, carousel, footer), and refining the styling to closely match the reference site. Each AI-generated output was reviewed and manually adjusted where needed, both in terms of structure and styling.

## Features Implemented
- Navbar
- Search bar
- Carousel
- Footer

## Notes
Scope was intentionally kept to the homepage only, to keep the result polished and within the given timeframe, rather than expanding into multiple unfinished pages.
